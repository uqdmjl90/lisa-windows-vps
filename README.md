具体流程是这样的：你先正常下单一台VPS（选Linux系统完成开通），开通后在客户中心提交工单，说明需要安装Windows系统，客服会在后台帮你处理，处理完成后你会拿到一个Windows的管理员密码，用来做远程桌面登录。这个模式在很多住宅IP/原生IP服务商里都比较常见，因为很多镜像库对Windows的授权和维护成本更高，不会像Linux发行版那样直接放在自助面板里让你点一下就装。

## 装好Windows之后怎么远程连接

工单完成Windows安装后，连接方式和普通云服务器基本一致，官网知识库也给出了具体步骤：

1. 如果本地是Windows系统，直接打开系统自带的"远程桌面连接"程序即可，不需要额外安装软件。
2. 如果本地是Mac，需要先在Mac App Store下载"Microsoft Remote Desktop"客户端。
3. 如果本地是Ubuntu等Linux桌面系统，需要安装对应的远程桌面客户端软件。

连接时填写的信息根据你的机器是否为独立IP有所不同：

- **独立IP机器**：服务器地址填 `公网IP:3389`，用户名 `Administrator`，密码就是控制面板里显示的系统密码。
- **NAT非独立IP机器**：需要先在控制面板里找到3389端口映射后的外部端口号，服务器地址填 `公网IP:映射后的端口`，用户名密码同上。

官网还特别提示，通过浏览器内置VNC连接会因为经过服务器跳转导致速度变慢，直接用RDP客户端连接体验会明显更好。如果连接过程中遇到问题，可以通过Telegram用户群或工单联系客服协助排查。

## 常见问题

**买普通套餐后能不能自己在面板里装Windows？** 目前来看不能直接自助安装，需要提交工单，由客服在后台完成部署，属于人工处理而非自动化镜像。

**装Windows要不要额外付费？** 从现有资料看，安装本身没有被提及单独收费，但内存配置直接决定能不能用得顺畅，建议至少选2GB内存起步的套餐。

**IP不满意可以换吗？** 可以。刚开通的机器如果对分配到的IP不满意，通常可以申请免费更换一次，年付套餐用户后续更换也相对宽松，月付用户如果要再次更换IP一般需要补差价，具体收费标准建议直接提工单跟客服确认。

**退款政策是怎样的？** 标准产品支持48小时内不满意无条件退款，但要注意，超过5%的带宽额度或20GB用量（以较小者为准）的服务不再符合退款条件，另外部分"住宅IP VDS"类特殊产品只能退到网站余额，不能原路退回。

**支付方式支持哪些？** 官网及多篇测评都提到支持支付宝、微信支付，国际用户也可以用信用卡或USDT，国内用户购买没有额外门槛。
